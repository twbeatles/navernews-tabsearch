# Feature Specification: UI 간소화

**Feature Branch**: `005-ui-simplification`

**Created**: 2026-10-06

**Status**: Approved

**Input**: User description: "뉴스를 탭으로 보는 앱의 목적에 맞게 UI/UX를 리팩토링한다. 과도한 UI는 덜어내고 쉽게, 뉴스앱으로서의 기능에 충실하게 다듬는다."

## 범위 결정

- **재배치·숨김만 한다.** 기능, 저장 데이터, config/import/export 계약은 바꾸지 않는다.
- 기사 목록은 기존 `QTextBrowser` HTML 렌더링을 유지한다(위젯 교체 없음).
- 테스트와 다른 모듈이 의존하는 위젯 속성명(`btn_refresh`, `btn_add`, `btn_load`, `btn_read_all`, `lbl_status`, `btn_advanced`, `btn_apply_date`, `btn_clear_date` 등)은 유지한다.

## User Scenarios & Testing

### User Story 1 - 첫 화면에서 바로 읽는다 (Priority: P1)

사용자는 앱을 열면 탭과 기사 목록을 먼저 본다. 상단에는 새로고침, 기사 검색, 더보기, 새 탭만 있고, 기사 카드에는 제목·요약·출처·시간과 북마크·공유만 있다.

**Independent Test**: 메인 창을 띄워 상단 버튼이 4개인지, 카드의 인라인 액션이 북마크·공유뿐인지 확인한다.

**Acceptance Scenarios**:

1. **Given** 메인 창, **When** 상단 툴바를 보면, **Then** `새로고침`, `기사 검색`, `더보기`, `새 탭` 버튼만 보인다.
2. **Given** 더보기 메뉴, **When** 열면, **Then** 내보내기·통계·태그 관리·자동화 규칙·출처 별칭·백업 및 복원·업데이트 확인·설정·도움말에 모두 접근할 수 있다.
3. **Given** 키워드 탭의 기사 카드, **When** 렌더링되면, **Then** 탭 키워드 배지는 반복되지 않고 사용자 태그와 "유사" 표시만 붙는다.
4. **Given** 기사 카드, **When** 우클릭하면, **Then** 메모·태그·읽음 전환·출처 차단/선호·삭제를 그대로 쓸 수 있다.
5. **Given** 읽은 기사, **When** 목록에 표시되면, **Then** 제목이 흐린 색·보통 굵기로 구분된다.

### User Story 2 - 걸려 있는 필터를 놓치지 않는다 (Priority: P1)

고급 필터(선호 출처·태그·기간)가 접힌 상태에서도 조건이 걸려 있으면 사용자가 알 수 있고, 한 번에 해제할 수 있다.

**Independent Test**: 태그 필터를 건 뒤 고급 영역을 접고, 버튼 표시와 초기화 동작을 확인한다.

**Acceptance Scenarios**:

1. **Given** 고급 필터 조건이 하나 이상 활성, **When** 고급 영역이 접혀 있으면, **Then** 토글 버튼이 `필터 ●`로 표시된다.
2. **Given** 어떤 필터든 활성, **When** `초기화`를 누르면, **Then** 텍스트·안 읽음·중복 숨김·선호 출처·태그·기간이 모두 해제되고 목록이 한 번 다시 조회된다.
3. **Given** 활성 필터가 없음, **Then** `초기화` 버튼은 보이지 않는다.

### User Story 3 - 상태를 한눈에 읽는다 (Priority: P2)

탭 하단 상태는 `기사 120개 · 안 읽음 8 · 10:32 업데이트` 형태의 짧은 문장이다. "더 보기"(저장된 기사 더 표시)와 "이전 기사 가져오기"(API 추가 수집)는 문구로 구분된다.

**Acceptance Scenarios**:

1. **Given** 필터 없는 키워드 탭, **Then** 상태는 `기사 N개`로 시작하고 안 읽음·업데이트 시각이 `·`로 이어진다.
2. **Given** 필터 활성, **Then** `N개 일치 (전체 M개)`로 표시된다.
3. **Given** 키워드 탭에서 API에 더 가져올 기사가 있음, **Then** 하단 버튼은 `이전 기사 가져오기`이고, 없으면 비활성 `모두 가져옴`이다.

### User Story 4 - 설정을 찾기 쉽다 (Priority: P2)

설정은 `일반` / `알림·트레이` / `데이터` / `도움말` / `단축키` 탭으로 나뉜다. 저장되는 값은 이전과 같다.

**Acceptance Scenarios**:

1. **Given** 설정 창, **Then** 위 다섯 탭이 순서대로 있다.
2. **Given** 도움말 모드(F1), **Then** 도움말·단축키 탭만 있고 첫 탭이 도움말이다.
3. **Given** 설정 저장, **Then** `get_data()`의 키 집합은 변경 전과 동일하다.

### Edge Cases

- 유지보수 모드에서는 내보내기 메뉴 항목과 필터 초기화 버튼도 비활성화된다.
- 북마크 탭에는 "이전 기사 가져오기" 버튼이 없다(기존과 동일).
- 저장 검색을 적용해 고급 필터가 복원되면 고급 영역이 자동으로 펼쳐진다(기존과 동일).
- 시스템 테마 자동(theme=2)일 때 설정 창도 실제 적용 테마를 따른다.

## Requirements

- **FR-001**: 상단 툴바는 `새로고침`, `기사 검색`, `더보기`, `새 탭` 4개 버튼으로 구성한다.
- **FR-002**: 기존 툴바의 내보내기·백업·도움말·업데이트·설정은 더보기 메뉴 액션으로 옮기고, 단축키는 그대로 동작한다.
- **FR-003**: 기사 카드 인라인 액션은 북마크(해제)·공유 2개다. 나머지 액션의 `app://` 처리와 우클릭 메뉴는 유지한다.
- **FR-004**: 키워드 탭 카드에 탭 키워드 배지를 붙이지 않는다.
- **FR-005**: 고급 필터 활성 여부를 토글 버튼에 표시하고, 필터가 하나라도 활성일 때만 `초기화` 버튼을 노출한다.
- **FR-006**: 탭 우클릭 메뉴의 "페이징 커서 초기화"는 "처음부터 다시 불러오기"로 표기한다(동작 동일).
- **FR-007**: 새 탭 대화상자에서 하드코딩된 추천 키워드와 내부 구현 설명을 제거한다.
- **FR-008**: 설정 창을 탭으로 분리하되 위젯 속성명과 `get_data()` 계약을 유지한다.
- **FR-009**: 앱 QSS에서 그라데이션을 제거하고, 강조색 버튼은 `새 탭` 하나만 둔다. padding·radius를 줄여 기사 영역을 넓힌다.
- **FR-010**: 설정·대화상자의 인라인 하드코딩 색상(`#666`, `#1A1A1D`, 도움말 `#007AFF`)을 팔레트 토큰/QSS 규칙으로 대체한다. 통계 창의 수치 강조색은 범위 밖이다.
- **FR-011**: 버튼·메뉴 라벨의 장식용 이모지를 제거한다. 상태/토스트 메시지의 기호는 유지한다.

## Success Criteria

- **SC-001**: 상단 툴바 버튼 수 9 → 4.
- **SC-002**: 카드당 인라인 액션 수 5~6 → 2.
- **SC-003**: `python -m pytest -q` 결과가 변경 전 대비 새 실패 0건, `python -m pyright` 오류 0건.
- **SC-004**: 라이트/다크 양쪽에서 메인 창·설정 창 오프스크린 렌더 결과를 육안 확인한다.

## Assumptions

- VERSION 및 `update_history.md` 변경은 릴리스 시점에 별도로 한다.
- 기사 목록 위젯 교체(QListView delegate), 기능 삭제는 범위 밖이다.
