# 뉴스 스크래퍼 Pro (News Scraper Pro)

관심 키워드별로 네이버 뉴스를 실시간 수집하고, 읽음·북마크·메모·태그·자동화 규칙으로 체계적으로 관리하는 **Windows 전용 데스크톱 뉴스 모니터링 프로그램**입니다.

수집된 모든 기사는 로컬 PC(SQLite DB)에 영구 보관되므로 과거 기사를 언제든 다시 찾아볼 수 있으며, 여러 주제를 탭으로 분리하여 동시에 모니터링할 수 있습니다.

## 🎯 이런 분께 추천합니다

- **기업 / 시장 / 경쟁사 모니터링**: 매일 특정 회사, 브랜드, 신기술 동향을 빠짐없이 확인해야 하는 분
- **광고·채용 없는 깔끔한 뉴스 수집**: `-광고`, `-채용`, `-홍보` 등 제외어를 사용해 노이즈 없는 고품질 기사만 골라보고 싶은 분
- **스크랩 & 리서치 업무**: 중요 기사에 북마크(⭐), 메모(📝), 태그(🏷)를 달아 체계적으로 아카이빙하고 보고서(CSV, Markdown)로 내보내고 싶은 분
- **다중 키워드 동시 추적**: 여러 검색 주제를 탭으로 분리하여 각기 다른 자동 새로고침 주기로 모니터링하고 싶은 분
- **멀티 PC 환경 사용자**: 집, 사무실, 노트북 간에 기사 읽음/북마크/메모 상태를 클라우드 폴더로 동기화하고 싶은 분

## 🚀 빠른 시작 가이드

### 1. 프로그램 실행

#### A. 배포본(실행 파일)으로 실행
- 내려받은 `NewsScraperPro_Safe.exe` 파일을 실행합니다.
- 설치 과정 없이 즉시 실행되는 포터블 형태입니다.

#### B. 소스코드에서 직접 실행 (개발자용)
- Python 3.10 이상 환경에서 다음 명령어를 실행합니다. 릴리스 CI에서 검증하는 기준 환경은 Windows x64 / Python 3.14입니다:
```bash
pip install -r requirements.txt
python news_scraper_pro.py
```

### 2. 네이버 API 키 발급 (필수, 최초 1회)

뉴스를 수집하려면 네이버 클라우드 플랫폼의 **NAVER API HUB** 키가 필요합니다.  
*(※ 기존 네이버 개발자센터 키(`openapi.naver.com`)는 지원되지 않습니다.)*

1. [네이버 클라우드 플랫폼(Ncloud)](https://www.ncloud.com/)에 접속하여 회원가입 및 로그인합니다.
2. 상단 콘솔로 이동 후 **Services → Application Services → NAVER API HUB**를 선택합니다.
3. **Application 등록** 버튼을 클릭합니다.
   - Application 이름 입력 (예: `MyNewsScraper`)
   - 사용할 API 목록에서 **검색 (Search - 뉴스)**를 체크하여 추가합니다.
4. 등록 완료 후 생성된 Application의 **인증 정보 (Authentication)**를 클릭하여 **Client ID**와 **Client Secret** 값을 복사합니다.

> 📘 **참고 안내서**: [NAVER API HUB 공식 사용 가이드](https://guide.ncloud-docs.com/docs/apihub-use)

---

### 3. 앱에 API 키 등록 및 검증

1. 앱 실행 후 도구막대의 **⚙ (설정)** 버튼을 클릭하거나 단축키 `Ctrl+,`를 누릅니다.
2. **네이버 API 설정** 영역에 복사한 **Client ID**와 **Client Secret**을 붙여넣습니다.
3. **✓ API 키 검증** 버튼을 클릭합니다.
   - `✅ API 키가 유효합니다!` 메시지가 나타나면 정상입니다.
4. 하단의 **저장** 버튼을 누릅니다.

---

### 4. 첫 번째 뉴스 탭 만들기

1. 도구막대 우측의 **➕ 새 탭** 버튼을 누르거나 단축키 `Ctrl+T`를 누릅니다.
2. 관심 검색어를 입력합니다. (예: `인공지능 AI -광고`, `삼성전자 -주가`)
3. **확인**을 누르면 새 탭이 생성되고 최신 뉴스가 자동으로 수집되어 화면에 표시됩니다!

## 📖 상세 사용 가이드

### 1. 스마트 검색어 문법 & 탭 관리

#### 🔍 검색어 입력 문법
탭 생성 시 다양한 연산자를 조합하여 불필요한 기사를 사전에 걸러낼 수 있습니다.

| 검색어 예시 | 설명 |
|---|---|
| `삼성전자` | '삼성전자'가 포함된 최신 뉴스 수집 |
| `삼성전자 -주가` | '삼성전자' 뉴스 중 '주가'라는 단어가 들어간 기사 제외 |
| `인공지능 AI -채용 -광고` | '인공지능'과 'AI'를 모두 포함하며, '채용'과 '광고'가 들어간 기사 제외 |
| `전기차 배터리 -리콜` | '전기차'와 '배터리'를 모두 포함하고 '리콜'은 제외 |

> ⚠️ **주의**: `-광고`처럼 제외어만으로 구성된 검색어는 사용할 수 없으며, 최소 1개 이상의 일반 검색 키워드가 필요합니다.

#### 📑 탭 관리 기능
- **탭 이동**: 탭을 마우스로 드래그하여 순서를 변경할 수 있습니다.
- **탭 이름 변경**: 탭 머리글을 **더블 클릭**하거나 탭 우클릭 후 **✏️ 이름 변경**을 선택합니다.
- **탭 닫기**: 탭의 `X` 버튼을 누르거나 탭 활성화 상태에서 `Ctrl+W`를 누릅니다. (첫 번째 `⭐ 북마크` 탭은 고정)
- **탭 바로가기**: `Alt+1` ~ `Alt+9` 단축키로 원하는 탭으로 즉시 전환합니다.

#### 🖱️ 탭 우클릭 컨텍스트 메뉴
탭 머리글을 마우스 오른쪽 버튼으로 클릭하면 강력한 전용 메뉴가 나타납니다:
- **🔄 새로고침**: 해당 탭의 기사만 즉시 새로고침
- **✏️ 이름 변경**: 검색어 및 탭 제목 수정
- **⏰ 자동 새로고침 주기 설정**: 탭별로 전역 설정을 따르지 않고 개별 주기(10분, 30분, 1시간, 2시간, 6시간, 끔)를 다르게 지정 가능
- **📁 그룹에 추가**: 탭을 특정 키워드 그룹에 등록하여 분류
- **⏮ 페이징 커서 초기화**: API 수집 시작 위치를 처음(1페이지)으로 리셋하여 과거 기사를 처음부터 다시 스캔
- **❌ 탭 닫기**: 해당 탭 삭제

### 2. 강력한 필터 시스템

각 뉴스 탭 상단에는 수집된 수백~수천 개의 기사 중 원하는 기사만 즉시 추출할 수 있는 다단계 필터 카드가 내장되어 있습니다.

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [🔍 제목/내용 필터       ] [최신순 ▾] [ ] 안 읽은 것만  [ ] 중복 숨김  [고급 필터 ▾] │
├─────────────────────────────────────────────────────────────────────────────┤
│ (고급 필터 열림 시)                                                          │
│ [ ] 선호 출처만   태그: [전체 ▾      ]   [📅 기간 ▾] [2026-08-01 ~ 2026-08-18]   │
│ 저장 검색: [선택 ▾                ] [적용] [검색 저장] [삭제]                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **실시간 텍스트 필터 (`Ctrl+F`)**: 제목이나 본문(description)에 입력한 단어가 포함된 기사만 즉시 필터링 (다중 단어 입력 시 공백으로 구분하여 AND 검색)
- **정렬 옵션**: `최신순` / `오래된순` 즉시 전환
- **안 읽은 것만**: 읽지 않은 새로운 기사만 모아보기
- **중복 숨김**: 동일하거나 유사한 내용의 중복 기사를 숨겨 리딩 시간 단축
- **고급 필터 펼치기**:
  - **선호 출처만**: 설정에서 등록한 '선호 언론사' 기사만 선별
  - **태그 필터**: 특정 태그(`#{태그명}`)가 부여된 기사만 필터링
  - **기간(Date) 필터**: 시작일과 종료일을 캘린더에서 지정하여 특정 날짜 범위의 기사만 조회
  - **저장된 검색**: 자주 사용하는 복합 필터 조건(검색어+정렬+태그+날짜 등)을 이름 붙여 저장하고 원클릭으로 불러오기

### 3. 기사 카드 관리 & 액션

수집된 기사는 세련된 카드 형태로 표시되며 다양한 사용자 인터랙션을 지원합니다.

- **기사 읽기**: 기사 제목을 클릭하면 **자동으로 읽음 처리**되며 기본 웹 브라우저에서 원문 기사가 열립니다.
- **마우스 호버 미리보기**: 기사 제목 위에 마우스를 올리면 기사 본문 요약 툴팁이 팝업됩니다.
- **기사 카드 하단 액션 버튼**:
  - `공유`: 기사 제목과 URL을 클립보드에 깔끔하게 복사
  - `외부`: 브라우저에서 원문 페이지 열기
  - `메모`: 기사에 사용자 메모 작성 (최대 10,000자 지원, 메모가 있는 기사는 📝 아이콘 표시)
  - `태그`: 쉼표로 구분하여 여러 개의 사용자 태그 부여 (예: `중요, 2분기실적, AI`)
  - `안읽음`: 이미 읽은 기사를 다시 안 읽음 상태로 되돌리기
  - `북마크 / 북마크 해제`: 중요 기사를 북마크하여 첫 번째 `⭐ 북마크` 탭에서 영구 보관
- **기사 우클릭 컨텍스트 메뉴**:
  - 기사 카드 위에서 우클릭하면 `브라우저로 열기`, `복사`, `북마크`, `메모`, `태그`, `🚫 이 출처 차단`, `✓ 이 출처 선호 추가`, `🗑 목록에서 삭제`를 바로 수행할 수 있습니다.
- **하단 도구 버튼**:
  - `📥 더 불러오기`: 네이버 검색 API의 다음 페이지 결과를 추가로 수집
  - `✓ 모두 읽음`: 현재 화면에 표시된 모든 기사를 일괄 읽음 처리
  - `⬆ 맨 위로`: 스크롤을 기사 목록 최상단으로 이동

### 4. 전문가용 관리 도구

도구막대의 **🧰 관리** 메뉴를 통해 전문적인 데이터 정리 기능을 활용할 수 있습니다.

#### 📊 뉴스 통계 및 언론사별 분석
- 전체 저장된 기사 수, 읽은 기사, 북마크 기사, 메모 기사 통계 확인
- 가장 많이 보도된 언론사 Top 순위 및 점유율 차트/통계 제공

#### 🏷 태그 관리자 (`Ctrl+Shift+T`)
- 생성된 모든 태그 목록 조회 및 사용 빈도 확인
- 태그 이름 일괄 변경, 유사 태그 병합(Merge), 불필요한 태그 삭제
- 현재 탭에 열린 기사들에 특정 태그를 일괄 부여

#### 🤖 자동화 규칙 (`Ctrl+Shift+A`)
- 뉴스가 수집될 때 특정 조건에 맞으면 자동으로 액션을 수행하는 봇 규칙 설정
- **조건**: 포함 키워드, 제외 키워드, 특정 언론사(출처), 대상 검색 탭
- **실행 액션**: 자동 태그 추가, 자동 북마크 등록, 자동 읽음 처리
- 기존에 수집된 기사에도 소급하여 일괄 적용 가능

#### 📰 출처 Alias 관리
- 언론사 표기가 제각각인 경우(예: `조선일보`, `chosun.com`, `조선비즈`) 하나의 표준 이름으로 통일하여 표시
- 복잡한 출처 도메인을 깔끔한 한글 이름으로 매핑

#### 🗂 키워드 그룹 관리
- 업무별, 프로젝트별로 연관된 키워드 탭들을 하나의 그룹(예: `2차전지 모니터링`, `부동산 정책`)으로 묶어 체계적으로 관리

### 5. 아카이브 전체 검색 (`Ctrl+Shift+F`)

특정 탭에 국한되지 않고, **지금까지 PC에 저장된 모든 기사 데이터베이스**를 대상으로 통합 검색할 수 있는 전용 창입니다.

- 전체 기사 대상 통합 키워드 검색
- 기간 설정, 북마크 여부, 읽음 여부, 태그 조건 결합 검색
- 검색 결과를 확인하고 즉시 메모 작성, 북마크 토글, CSV 내보내기 가능

### 6. 데이터 내보내기 & 가져오기

- **현재 결과 내보내기 (`Ctrl+S`)**:
  - 현재 탭(또는 필터링된 결과)의 기사 목록을 **CSV** 또는 **Markdown (.md)** 파일로 즉시 저장
  - 보고서 작성, 노션(Notion) 정리, 엑셀 분석용으로 최적화
- **설정 내보내기 / 가져오기**:
  - 탭 목록, 키워드 그룹, 자동화 규칙, 출처 Alias 설정을 JSON 파일로 백업 및 다른 PC로 이전  
    *(※ 보안을 위해 API 키는 내보내기 대상에서 제외됩니다.)*
- **CSV 메모 / 북마크 가져오기**:
  - 이전에 내보낸 CSV 파일의 북마크 및 메모 데이터를 현재 DB 기사들에 다시 매핑하여 복원

---

### 7. 클라우드 동기화 & 자동 백업

#### ☁️ 클라우드 동기화 (Multi-PC Sync)
- **설정 방법**: **설정(Ctrl+,) → 데이터 관리 → 클라우드 동기화**에서 OneDrive, Google Drive, Dropbox, NAS 공유 폴더를 지정합니다.
- **동작 방식**: 
  - 수집된 기사 및 상태(읽음, 북마크, 메모, 태그, 삭제 기록)를 스냅샷 파일로 주기적으로 공유 폴더에 내보내고 병합(Import)합니다.
  - 여러 대의 PC에서 동일한 기사 상태를 유지하며 안전하게 이어볼 수 있습니다.

#### 🗂 자동 백업 및 롤백
- 설정한 주기(30분, 1시간, 6시간 등)마다 DB와 설정 파일을 ZIP 스냅샷으로 자동 백업합니다.
- 도구막대의 **🗂 (백업)** 버튼을 눌러 언제든 원하는 시점으로 안전하게 복원(Restore)할 수 있습니다.

### 8. 시스템 트레이 & 실시간 알림

- **백그라운드 모니터링**: 창을 닫아도 시스템 트레이로 최소화되어 설정된 주기마다 뉴스를 계속 자동 수집합니다.
- **Windows 시작 시 자동 실행**: PC 부팅 시 백그라운드(최소화 상태)로 자동 실행되도록 설정 가능합니다.
- **실시간 키워드 데스크톱 알림**:
  - `설정 → 알림 설정`에서 알림 키워드(예: `긴급, 속보, 특약, 공시`)를 등록해 두면, 해당 단어가 포함된 뉴스가 수집될 때 윈도우 데스크톱 알림 및 사운드로 즉시 알려줍니다.

### 9. GitHub 릴리스 자동 업데이트

- 도구막대 상단의 **⬆ (업데이트)** 버튼을 누르면 새로운 버전이 출시되었는지 확인합니다.
- 업데이트 파일은 SHA-256 해시와 전자서명(Ed25519)을 검증하여 안전하게 다운로드되며, 실패 시 이전 버전으로 자동 복구됩니다.

## ❓ 자주 묻는 질문 (FAQ) & 문제 해결

#### Q1. 예전에 사용하던 네이버 개발자센터 API 키를 넣었는데 동작하지 않습니다.
> **A.** 네이버 정책 변경에 따라 **NAVER API HUB** 엔드포인트만 지원합니다. [네이버 클라우드 플랫폼](https://www.ncloud.com/product/applicationService/naverApiHub)에서 API HUB 서비스를 신청하고 새 Application 키를 발급받아 입력해 주세요.

#### Q2. API 키 검증 시 인증 오류(401/403)가 발생합니다.
> **A.** 다음 사항을 확인해 주세요:
> 1. Client ID와 Client Secret 앞뒤에 공백이 들어가지 않았는지 확인합니다.
> 2. 네이버 클라우드 콘솔의 해당 Application 설정에서 **검색 (Search - 뉴스)** API가 서비스 목록에 추가되어 있는지 확인합니다.

#### Q3. '더 불러오기'를 눌러도 새로운 기사가 더 이상 나오지 않습니다.
> **A.** 네이버 검색 API 정책상 하나의 검색어 조합당 최대 약 1,000건(start=1000)까지만 조회가 가능합니다.
> - 더 많은 과거 기사를 보려면 검색 기간(Date Filter)을 좁히거나 키워드를 세분화하여 새 탭을 만드세요.
> - 처음부터 다시 조회하고 싶다면 탭 우클릭 후 **⏮ 페이징 커서 초기화**를 실행하세요.

#### Q4. 프로그램 데이터(DB, 설정, 로그)는 어디에 저장되나요?
> **A.** Windows의 기본 로컬 앱 데이터 폴더에 안전하게 보관됩니다:
> ```text
> %LOCALAPPDATA%\NaverNewsScraperPro
> (일반적인 경로: C:\Users\<사용자명>\AppData\Local\NaverNewsScraperPro)
> ```
> - 기사 데이터베이스: `news_database.db`
> - 환경설정 파일: `news_scraper_config.json`
> - 백업 아카이브: `backups/` 폴더

#### Q5. 다른 PC로 설정을 내보냈는데 API 키가 비어 있습니다.
> **A.** 보안을 위해 설정 내보내기 파일(JSON)에는 API 키가 포함되지 않는 것이 정상입니다. 새 PC에서 설정 창을 열고 API 키를 1회 직접 입력해 주세요.

#### Q6. 기사를 삭제했는데 DB 용량이 줄지 않습니다.
> **A.** `🗑 목록에서 삭제`는 즉시 완전 삭제가 아니라 **삭제 기록(tombstone)** 을 남깁니다. 이 기록이 있어야 클라우드 동기화로 다른 PC에서도 같은 기사가 삭제되고, 아카이브 전체 검색에서 복구할 수도 있습니다.
> - 설정 → 데이터 관리 → **삭제 기록 보존** 기간(기본 90일)이 지난 삭제 기록은 `🧹 오래된 데이터 정리` 또는 `🗑 모든 기사 삭제` 실행 시 실제로 제거되어 용량이 회수됩니다.
> - 클라우드 동기화를 쓰지 않는다면 보존 기간을 `7일`로 줄여도 됩니다. `영구 보존`을 고르면 삭제 기록은 회수되지 않습니다.
> - 현재 삭제 기록이 몇 건인지는 **🧰 관리 → 📊 통계**의 `💾 저장소` 항목에서 확인할 수 있습니다.

#### Q7. 프로그램이 중복 실행되지 않습니다.
> **A.** 데이터베이스 동시 접근 충돌을 방지하기 위해 단일 인스턴스로 동작합니다. 프로그램이 이미 실행 중인 경우 새로운 창이 뜨는 대신 기존 실행 창이 화면 맨 앞으로 활성화됩니다.

## 🛠 데이터 저장 경로 및 기술 스택

- **UI Framework**: Python PyQt6 (다크 모드 / 라이트 모드 / 시스템 테마 완벽 지원)

- **보안 & 안전성**: 설정 파일 백업 미러링, 서명 기반 자동 업데이트 롤백 지원
